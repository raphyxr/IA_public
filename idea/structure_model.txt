Pour ton pipeline, voici les fonctions/méthodes les plus utiles.

**`torch`**
- `torch.tensor(...)` : créer des tenseurs depuis tes IDs.
- `torch.long` : type pour les IDs (obligatoire pour `Embedding`).
- `torch.device("cuda" if torch.cuda.is_available() else "cpu")` : choisir GPU/CPU.
- `torch.argmax(logits, dim=-1)` : prendre le mot prédit.
- `torch.no_grad()` : inférence sans gradients.
- `torch.save(...)` / `torch.load(...)` : sauvegarder/recharger.

**`torch.nn`**
- `nn.Embedding(vocab_size, emb_dim)` : IDs -> vecteurs.
- `nn.LSTM(...)` ou `nn.GRU(...)` : modéliser la séquence.
- `nn.Linear(hidden_dim, vocab_size)` : projeter vers le vocabulaire.
- `nn.CrossEntropyLoss()` : loss pour prédiction du prochain token.
- `model.train()` / `model.eval()` : mode entraînement / évaluation.
- `model.parameters()` : donner les poids à l’optimiseur.
- `model.to(device)` : envoyer modèle sur GPU/CPU.

**`torch.optim`**
- `optim.Adam(model.parameters(), lr=...)` : optimiseur.
- `optimizer.zero_grad()` : reset gradients.
- `loss.backward()` : calcul des gradients.
- `optimizer.step()` : mise à jour des poids.

**`torch.utils.data`**
- `Dataset` : classe perso pour tes paires `(X, y)`.
- `DataLoader(dataset, batch_size=..., shuffle=True)` : batchs automatiques.

**Très utile en pratique**
- `tqdm(...)` : barre de progression.
- `json.dump(...)` / `json.load(...)` : sauvegarder `token2id`, `id2token`.
