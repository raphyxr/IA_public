## 📌 **2. Fonction Encodeur (à part)**
**Rôle** : Convertir du **texte** en une liste d’**indices** (en utilisant `word2idx`).

### **Implémentation**
```python
def encode(texte, word2idx, context_size=None):
    """
    Convertit du texte en une liste d'indices.
    Si context_size est précisé, tronque ou pad la liste à cette taille.

    Args:
        texte (str): Texte à encoder.
        word2idx (dict): Dictionnaire {mot: index}.
        context_size (int, optional): Taille maximale de la séquence.

    Returns:
        list[int]: Liste d'indices.
    """
    mots = texte.lower().split()
    indices = [word2idx.get(mot, word2idx.get('<unk>', 0)) for mot in mots]

    if context_size is not None:
        # Tronquer ou pad pour avoir exactement context_size éléments
        if len(indices) > context_size:
            indices = indices[-context_size:]
        else:
            indices = [word2idx.get('<pad>', 0)] * (context_size - len(indices)) + indices

    return indices
```

**Exemple d’utilisation :**
```python

indices = encode(texte, word2idx, context_size=5)
print(indices)  # Exemple: [0, 1, 0, 0, 0] si context_size=5 et '<pad>'=0
```

## 📌 **3. Le Modèle LSTM**
Ton modèle sera une **classe PyTorch** qui intègre toutes les étapes : préparation du prompt, encoding, embedding, LSTM, FC, et prédiction (argmax ou échantillonnage).

### **Structure de la classe**
```python
import torch
import torch.nn as nn

class MonModeleLSTM(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, context_size):
        super(MonModeleLSTM, self).__init__()
        self.context_size = context_size
        self.emb_layer = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, vocab_size)

    def forward(self, x):
        """
        Passe avant du modèle.

        Args:
            x (torch.Tensor): Tensor d'indices de mots (batch_size, seq_len).

        Returns:
            torch.Tensor: Logits pour chaque mot du vocabulaire (batch_size, seq_len, vocab_size).
        """
        embeds = self.emb_layer(x)  # (batch_size, seq_len, embed_dim)
        lstm_out, _ = self.lstm(embeds)  # (batch_size, seq_len, hidden_dim)
        logits = self.fc(lstm_out)  # (batch_size, seq_len, vocab_size)
        return logits

    def prepare_prompt(self, texte, word2idx):
        """
        Prépare le prompt pour le modèle (encode + tronque/pad).

        Args:
            texte (str): Texte du prompt.
            word2idx (dict): Dictionnaire {mot: index}.

        Returns:
            torch.Tensor: Tensor du prompt prêt pour le modèle.
        """
        indices = encode(texte, word2idx, self.context_size)
        return torch.LongTensor([indices])  # Ajoute une dimension batch

    def predict_next_word(self, prompt_tensor, temperature=1.0):
        """
        Prédit le prochain mot à partir d'un prompt.

        Args:
            prompt_tensor (torch.Tensor): Tensor du prompt (1, seq_len).
            temperature (float): Température pour l'échantillonnage.

        Returns:
            int: Index du prochain mot prédit.
        """
        with torch.no_grad():
            logits = self.forward(prompt_tensor)  # (1, seq_len, vocab_size)
            # On prend la sortie pour le dernier mot de la séquence
            next_token_logits = logits[0, -1, :] / temperature
            next_token_probs = torch.softmax(next_token_logits, dim=-1)
            next_token = torch.multinomial(next_token_probs, num_samples=1).item()
        return next_token
```

```python
def generate_text(model, word2idx, idx2word, prompt, max_length=50, temperature=1.0):
    """
    Génère du texte à partir d'un prompt.

    Args:
        model: Modèle LSTM chargé.
        word2idx: Dictionnaire {mot: index}.
        idx2word: Dictionnaire {index: mot}.
        prompt: Texte de départ.
        max_length: Longueur maximale de la génération.
        temperature: Température pour l'échantillonnage.

    Returns:
        str: Texte généré.
    """
    # Prépare le prompt
    prompt_tensor = model.prepare_prompt(prompt, word2idx)
    generated_indices = []

    for _ in range(max_length):
        # Prédit le prochain mot
        next_token = model.predict_next_word(prompt_tensor, temperature)
        generated_indices.append(next_token)

        # Met à jour le prompt pour la prochaine itération
        # On garde les derniers context_size tokens
        new_input = prompt_tensor.tolist()[0][1:] + [next_token]
        if len(new_input) > model.context_size:
            new_input = new_input[-model.context_size:]
        else:
            new_input = [word2idx.get('<pad>', 0)] * (model.context_size - len(new_input)) + new_input
        prompt_tensor = torch.LongTensor([new_input])

        # Arrête si on génère le token de fin
        if next_token == word2idx.get('<eos>', -1):
            break

    # Décode les indices générés
    generated_text = decode(generated_indices, idx2word)
    return generated_text
```
