GUIDE CLAIR - ETAPES POUR TON MODELE DE LANGAGE (IDs -> Embedding -> Prediction)

Objectif
- Entrer des IDs de mots.
- Predire le mot suivant.
- Corriger le modele avec la loss.

-------------------------------------------------------------------
1) Charger les IDs depuis dataset_ids.txt
-------------------------------------------------------------------
But
- Lire les entiers du fichier et les mettre en liste Python.

Fonctions utiles
- Python: open(), read(), split(), int()
- PyTorch: torch.tensor(..., dtype=torch.long)

Points importants
- Les IDs doivent etre des entiers.
- Pour nn.Embedding, le type doit etre torch.long.

Exemple
- ids_list = [12, 5, 98, 44, ...]

-------------------------------------------------------------------
2) Creer les exemples d'entrainement (contexte -> mot suivant)
-------------------------------------------------------------------
But
- Transformer la liste d'IDs en paires (X, y).
- X = sequence de longueur context_size
- y = token juste apres la sequence

Fonctions utiles
- Python: for, append
- PyTorch: torch.tensor(X, dtype=torch.long), torch.tensor(y, dtype=torch.long)

Shape attendue
- X: [num_samples, context_size]
- y: [num_samples]

Exemple
- context_size = 4
- ids = [10, 11, 12, 13, 14]
- X[0] = [10,11,12,13], y[0] = 14

-------------------------------------------------------------------
3) Faire les batches avec DataLoader
-------------------------------------------------------------------
But
- Eviter de tout entrainer d'un coup.

Fonctions utiles
- torch.utils.data.TensorDataset(X, y)
- torch.utils.data.DataLoader(dataset, batch_size=..., shuffle=True)

Points importants
- shuffle=True pendant l'entrainement.
- batch_size classique: 16, 32, 64.

-------------------------------------------------------------------
4) Construire le modele (Embedding + LSTM + Linear)
-------------------------------------------------------------------
But
- Embedding: IDs -> vecteurs
- LSTM: comprend la sequence
- Linear: scores sur tout le vocabulaire

Fonctions utiles
- nn.Module
- nn.Embedding(vocab_size, emb_dim)
- nn.LSTM(input_size=emb_dim, hidden_size=hidden_dim, batch_first=True)
- nn.Linear(hidden_dim, vocab_size)

Shape typique
- Entree IDs: [batch, seq_len]
- Embedding: [batch, seq_len, emb_dim]
- LSTM out: [batch, seq_len, hidden_dim]
- Dernier etat: out[:, -1, :] -> [batch, hidden_dim]
- Logits: [batch, vocab_size]

Point critique
- Ne PAS faire nn.LSTM(vecs).
- Il faut d'abord creer la couche: lstm = nn.LSTM(...)
- Puis l'appeler: out, _ = lstm(vecs)

-------------------------------------------------------------------
5) Definir la loss et l'optimiseur
-------------------------------------------------------------------
But
- Mesurer l'erreur et corriger les poids.

Fonctions utiles
- nn.CrossEntropyLoss()
- torch.optim.Adam(model.parameters(), lr=...)

Points importants
- CrossEntropyLoss attend:
  - logits: [batch, vocab_size]
  - y: [batch] avec IDs cibles (long)

-------------------------------------------------------------------
6) Boucle d'entrainement (ordre exact)
-------------------------------------------------------------------
But
- Faire apprendre le modele.

Ordre obligatoire
1. model.train()
2. optimizer.zero_grad()
3. logits = model(X_batch)
4. loss = criterion(logits, y_batch)
5. loss.backward()
6. optimizer.step()

Fonctions utiles
- model.train()
- optimizer.zero_grad()
- loss.backward()
- optimizer.step()

Erreur classique
- Oublier zero_grad() -> gradients s'accumulent.

-------------------------------------------------------------------
7) Evaluation (sans apprentissage)
-------------------------------------------------------------------
But
- Mesurer la performance sans modifier les poids.

Fonctions utiles
- model.eval()
- with torch.no_grad():

Points importants
- Pas de backward ni step en eval.

-------------------------------------------------------------------
8) Prediction du mot suivant
-------------------------------------------------------------------
But
- Donner un contexte et recuperer le prochain token.

Fonctions utiles
- model(context_ids)
- torch.argmax(logits, dim=-1)
- (optionnel) torch.softmax(logits, dim=-1), torch.topk(...)

Points importants
- Contexte en shape [1, seq_len]
- dtype torch.long

-------------------------------------------------------------------
9) Sauvegarde / Rechargement
-------------------------------------------------------------------
But
- Reutiliser le modele plus tard.

Fonctions utiles
- torch.save(model.state_dict(), "modele.pt")
- model.load_state_dict(torch.load("modele.pt", map_location=device))

Optionnel utile
- Sauver aussi token2id/id2token en JSON.

-------------------------------------------------------------------
10) Checklist avant execution complete
-------------------------------------------------------------------
- IDs valides (entiers, >= 0)
- vocab_size = max(ids) + 1
- Tous les IDs et labels en torch.long
- Shapes correctes (voir ci-dessus)
- Boucle train dans l'ordre exact
- La loss baisse sur plusieurs epochs

-------------------------------------------------------------------
Fonctions PyTorch minimales a connaitre (resume)
-------------------------------------------------------------------
