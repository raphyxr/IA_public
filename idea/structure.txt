version simple:
1) Je prends mon dataset.txt
2) Je decoupe le texte en mots (tokens)
3) Je transforme chaque mot en numero (id)
4) Je cree des exemples:
    - entree: quelques mots
    - sortie: le mot suivant
5) Je construis le modele:
    Embedding + LSTM (ou Transformer) + Linear
6) Entrainement en boucle:
    - le modele predit
    - je compare a la bonne reponse (loss)
    - je corrige les poids (backward + optimizer.step)
7) Je repete beaucoup de fois (epoques)
8) Je teste:
    - je donne un debut de phrase
    - le modele predit le mot suivant
9) Je sauvegarde le modele pour le reutiliser



version complète:

1) Preparation des donnees
    charger le texte:
        load_text(path) -> str
    nettoyer:
        normalize_text(text) -> str
    tokeniser:
        tokenize(text) -> list[str]
    construire le vocabulaire:
        build_vocab(tokens) -> token2id, id2token
    encoder les tokens en ids:
        encode_tokens(tokens, token2id) -> list[int]
    creer les sequences:
        create_sequences(ids, context_size) -> X, y

2) Modele
    embedding des ids:
        nn.Embedding(vocab_size, emb_dim)
    modele de sequence:
        nn.LSTM(...) ou Transformer
    projection finale vers vocabulaire:
        nn.Linear(hidden_dim, vocab_size)

3) Entrainement
    pour chaque batch (X_batch, y_batch):
        optimizer.zero_grad()
        logits = model(X_batch)
        loss = criterion(logits, y_batch)   # CrossEntropyLoss
        loss.backward()
        optimizer.step()
    repeter sur plusieurs epoques
    evaluer sur validation:
        evaluate(...)

4) Prediction
    donner un contexte (ex: "un chat")
    encoder en ids
    calculer logits = model(contexte)
    appliquer softmax -> probabilites
    prendre le mot le plus probable (ou top-k)

5) Sauvegarde
    sauvegarder:
        model.state_dict(), token2id, id2token
    recharger pour reutiliser le modele




temperature:


Choisir le prochain mot

On a un tableau de probabilités pour chaque mot (ex: [0.01, 0.7, 0.05, ...]).
2 méthodes pour choisir le prochain mot :

Argmax : Prendre le mot avec la plus haute probabilité (déterministe, peu créatif).
Échantillonnage (avec température) :

On ajuste les probabilités avec la température :

temperature = 1.0 : probabilités inchangées.
temperature < 1.0 : favorise les mots probables (texte plus cohérent).
temperature > 1.0 : donne plus de chance aux mots improbables (texte plus créatif/aléatoire).

On tire au hasard un mot selon ces probabilités (avec torch.multinomial).
